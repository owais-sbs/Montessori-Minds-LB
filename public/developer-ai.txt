## Technical Overview

Public marketing website for a Montessori preschool / nursery in Choueifat, Lebanon. There is no public developer API, SDK, or authenticated customer portal for third-party integrations.

Primary web property: https://www.montessorimindslb.com/

## Website

Platform: React + Vite SPA with prerendered crawlable HTML bodies
Hosting: Vercel
Purpose: Present campus programs, admissions path and visit booking for families

Public areas:
- Home, La Casa Verde, Our approach, Programs
- Nursery, Pre-school, Admissions, FAQ, Gallery
- Book a visit form
- AI Discovery Files at site root

No authentication required for public content.
